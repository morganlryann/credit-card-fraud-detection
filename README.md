# Credit Card Fraud Detection
Machine learning project for detecting fraudulent credit card transactions using Python and Scikit-learn.

## Project Overview
A machine learning project designed to identify fraudulent credit card transactions using Python and Scikit-learn.

## Business Problem
Credit card fraud creates financial losses for banks, merchants, and consumers. The objective is to develop a model that identifies fraudulent transactions while minimizing false positives.

## Dataset
Source: Kaggle Credit Card Fraud Detection

https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

The dataset contains 284,807 transactions and 492 fraudulent transactions.

Download creditcard.csv from Kaggle and place it in the data/ directory.
